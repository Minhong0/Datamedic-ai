## 반환 형식 (JSON만, 설명 없이)
```json
[
  {
    "source": "시트명.컬럼명",
    "group_by": "그룹 기준 컬럼명",
    "agg": "sum 또는 count",
    "target": "요약시트명.컬럼명"
  }
]
```

## 규칙
- 합계 관계가 확실하지 않으면 포함하지 마세요
- group_by 컬럼은 양쪽 시트에 모두 있어야 합니다
- 결과가 없으면 빈 배열 [] 반환
